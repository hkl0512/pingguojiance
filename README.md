# 苹果品质检测

给一张苹果照片，在浏览器里直接判断它是不是「好苹果」：给出总分、四个分项，并在图上圈出检测到的碰伤与褐变。

纯前端实现，单个 HTML 文件，无依赖、不联网、照片不上传。双击即用。

## 功能

- **拖拽 / 点击 / 拍照 / 粘贴** 四种方式提供照片，支持 JPG、PNG、WebP。
- **综合评分**：0–100 分，分「特级 / 良好 / 一般 / 较差」四档。
- **四个分项**：完好度、色泽、光泽、果形，每项都有独立分数和进度条。
- **瑕疵标注**：在原图上圈出检测到的每一处瑕疵，并画出果实识别框。
- **文字结论**：逐条说明加分项和扣分项，不是只给一个数字。
- **检测灵敏度**：1–5 档，从「只报明显腐烂」到「小暗点也不放过」，调完立即重算。
- **内置示例**：没有照片时可以点「好苹果 / 有瑕疵」直接体验完整流程。

## 快速开始

双击 `index.html`，或用浏览器打开它。不需要安装任何东西，也不需要联网。

## 判断依据

| 指标 | 权重 | 看的是什么 |
| --- | --- | --- |
| 完好度 | 0.46 | 碰伤、褐变、腐烂的可见面积与处数 |
| 色泽 | 0.27 | 饱和度浓度、亮度、果面颜色是否均匀 |
| 光泽 | 0.13 | 表皮自然高光占比，反映蜡质层是否完好 |
| 果形 | 0.14 | 果体是否接近圆形、轮廓是否饱满 |

总分 85 以上为特级，72–84 良好，58–71 一般，58 以下较差。

核心技术思路：缩小到 420px → RGB 转 HSV → 按色相范围初筛果体 → 取最大连通域锁定苹果 → 补洞 → 沿果径内缩 5% 去掉虚焦过渡带 → 逐像素判瑕疵（色相偏褐 / 亮度低于亮面 / 饱和度下降，三者满足其一）→ 聚类成「几处瑕疵」→ 加权打分。

其中「饱和度下降」是区分**阴影**与**真淤伤**的关键：阴影只是同色变暗，HSV 里饱和度基本不变；淤伤是褐化加失水，饱和度会掉。

## 拍摄建议

想让它判得准，照片满足这几点就够了：

1. **单果入镜**，画面里只放一个苹果。
2. **背景简洁**，避免红桌布、木地板这类同色系大面积背景。
3. **光线均匀**，避免单侧强光和逆光；自然散射光最好。
4. **苹果占画面 1/3 以上**，拍大一点，小瑕疵才看得见。
5. 竖拍横拍都行，会自动按 EXIF 方向校正。

## 能力边界

只看照片里拍得到的那一面。内部霉心、农残、打蜡、口感甜度都无法从外观判断；背景与苹果同色、光线过暗或过曝时，结果会偏保守或偏激进。

这是基于图像特征的启发式判断，用于挑选参考，不构成食品安全结论。
