# 苹果品质检测

上传一张苹果照片，在浏览器本地判断它是不是「好苹果」：给出总分、四个分项（完好度 / 色泽 / 光泽 / 果形），并在图上圈出检测到的碰伤与褐变。

纯前端实现：单个 HTML 文件，无依赖、不联网、照片不上传，双击即用。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 主页面，照片检测功能 |
| `检测原理详解.html` | 逐环节技术拆解（含可交互的中间结果演示） |

## 本地打开

双击 `index.html`，或拖进浏览器窗口。

## 部署到 GitHub Pages

> 关键前提：**仓库必须是 public**。免费账号的私有仓库无法开启 Pages，这是「本地能开、线上打不开」最常见的原因。

1. 把本目录下的**文件**上传到仓库（不要让仓库根目录再套一层文件夹，除非你打算连文件夹名一起写进网址）。
2. 打开仓库 → **Settings**（顶部标签） → 左侧 **Pages**。
3. **Source** 选 `Deploy from a branch`；**Branch** 选 `main`，目录选 `/ (root)`，点 **Save**。
4. 等 1–2 分钟，页面顶部会出现网址：

```
https://<你的用户名>.github.io/<仓库名>/
```

因为主文件名是 `index.html`，访问根路径就会自动打开检测页。原理文档的地址是：

```
https://<你的用户名>.github.io/<仓库名>/检测原理详解.html
```

（中文文件名在网址里会被编码成 `%E6%A3%80...` 这样的串，能打开，但手打很麻烦。想清爽一点，把文件改名为 `principle.html`，同时把 `index.html` 底部那个链接的 `href` 一起改掉。）

## 常见问题：为什么 GitHub 上打不开

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 点开文件看到的是**源代码** | GitHub 的文件页只展示文本，不渲染 HTML。这是正常行为，不是坏了。 | 开 Pages，或把地址前面加上 `https://htmlpreview.github.io/?` |
| 打开是 **404** | 没开 Pages；或网址漏了仓库名；或文件在子目录 | 检查 Settings → Pages；网址写成 `.../仓库名/` 而不是 `.../仓库名/文件.html` 之外的猜测路径 |
| Pages 设置好了还是 404 | 刚保存，构建还没完成 | 等 1–2 分钟刷新；在 Actions 标签能看到构建进度 |
| Pages 里找不到开启按钮 | 仓库是 private（免费账号） | 仓库改成 public |
| 用 Raw 链接打开变成**下载**或乱码 | `raw.githubusercontent.com` 返回的是纯文本类型，浏览器不会当网页渲染 | 用 Pages 网址；或加 htmlpreview 前缀 |
| 打开是空白页 | 文件名/路径大小写不符（GitHub 区分大小写，Windows 不区分） | 检查实际文件名与你访问的路径是否完全一致 |

## 技术要点

- 降采样到 420px → RGB 转 HSV → 色相范围初筛 → 最大连通域锁定苹果 → 补洞 → 沿果径内缩 5% 去掉虚焦过渡带。
- 瑕疵判定三条并联：色相偏离主色（褐变）、比整果 p75 亮度明显更暗、饱和度下降（失水褪色）。**饱和度下降是区分「阴影」和「真淤伤」的关键**——阴影是同色变暗，HSV 里 S 不变。
- 打分：完好度 0.46 + 色泽 0.27 + 光泽 0.13 + 果形 0.14。

## 局限

只看照片里拍得到的那一面；内部霉心、农残、口感无法判断；背景与苹果同色时容易出错。结果仅供挑选参考，不构成食品安全结论。
